# 工业科幻视觉系统（frontend-industrial-sci-fi）

这不是「把两个现成风格拼起来」。科研机构侧给的是**信息如何被组织**，工业秩序侧给的是**元素如何被约束**。
两者在五个点上正面冲突（圆角、强调色数量、信息密度、动效、字体），本 skill 的第一件事就是逐条裁决，而不是让它们各占一半。

一句话立场：**界面像一台被校准过的仪器，不像一张被设计过的海报。**

## 一、什么时候用 / 不用

**用**

- 要做控制台、监控大屏、设备管理台、科研数据面板、调度台、档案检索系统。
- 用户说「工业风」「科幻感」「HUD」「赛博但克制」「像游戏里的终端」。
- 后台系统字段太多、扫不动 —— 需要按信息层级重排，而不是换配色。
- 已经有切角，但切得像贴上去的贴纸（切角与边框脱开、四角乱切）。
- 一个页面出现五个强调色，按钮色和告警色撞车。
- 需要「状态」这件事被正确表达：正常 / 警告 / 中断，并且不能被用户错过。

**不用**

- 要的是玻璃材质、折射、半透明面板：交给 `frontend-liquid-glass`。那是材料问题，本 skill 不碰。
- 要的是粒子、星云、体积光、WebGL 背景：交给 `frontend-particles`。本 skill 的背景永远是纯色或极弱网格。
- 要的是苹果式大幅留白、滚动叙事、大标题逐屏推进：交给 `frontend-apple-minimal`。它的留白是主角，本 skill 的留白只是分组间隔。
- 要的是二次元角色立绘、角色与 UI 的空间关系：交给 `frontend-anime-fusion`。本 skill 里不出现任何人形。
- 只是要一个普通后台管理界面、不需要品牌语言：不加载任何 skill，用常规设计系统即可；硬套工业风会让可读性下降。

## 二、核心原则与硬边界

### 原则 1：只有一个强调色，它表示「你在这里」

全站只有一个信号色：冷底上 `#C8F04B`。它只承担三种含义 —— **当前所在位置**、**可点击**、**需要立刻看一眼**。
一个颜色背三种含义之所以不冲突，是因为这三件事在时间上互斥：你不可能同时「在某个 tab 上」又「被别处提醒」。

状态（正常 / 警告 / 中断）走的是**另一条通道**：琥珀 `#E8A33D` 与赤 `#E2453C`。
它们是语义色，不是强调色 —— 状态色**不允许**出现在按钮、选中态、链接上。

**硬边界**：本 skill 只决定工业科幻视觉系统的语言、Token 与状态规则。苹果式大幅留白叙事、二次元角色立绘、粒子算法、玻璃折射参数不在职责内，即使它们能让画面更炫。

### 原则 2：切角是结构，不是装饰

切角只切**对角两角**（右上 + 左下），切深由元素等级决定：chip 4px、card 8px、panel 14px。
四角全切会退化成「八边形贴纸」；只切一角只像圆角坏了。对角切给元素一个方向感，方向感就是秩序感。

切角必须与 1px 边框**同一条路径**：外框用切角路径填充线色，内层 inset 1px 用切角路径填充面色。
内层切深不是 `cut - 1`，而是 `cut - 1.414`（45° 倒角内缩 1px，截距正好减 √2）。

**硬边界**：`border-radius` 恒为 0。任何元素只要出现一个非零圆角，即退回。

### 原则 3：用留白分组，不用减字段

科研侧要高密度（一屏 60 个读数），工业侧要克制（一屏 12 个元素）。这两者不矛盾：
**字段全部保留，用"段间距"分级**。同一段内行距 4px，段与段之间 24px，区块之间 48px —— 比例 1:6:12。
密度靠间距的**比值**建立，不靠删东西。

**硬边界**：正文与背景对比度 ≥ 4.5:1，次要信息 ≥ 3:1。降级只能用字号与字重，不能用低于 3:1 的灰。

### 原则 4：颜色不插值，几何才插值

状态从 NOMINAL 跳到 INTERRUPT 时，颜色**瞬时切换（0ms）**；同一帧里，状态条的宽度用 140ms 过渡。
理由：颜色渐变会让告警"慢慢浮现"，用户可能整段错过；几何过渡则帮助眼睛追踪"是哪一条变了"。

**硬边界**：一个模块的状态只能单向升级（NOMINAL → CAUTION → INTERRUPT），降级必须经过显式 RESET 动作。自动降级即退回。

### 原则 5：字体的分工由「可不可扫」决定，不由「好不好看」决定

- 标签（英文、全大写、`font-stretch: 125%`、字距 0.14em、10–11px）—— 用来**定位**，不用来读。
- 数据（等宽数字、`tabular-nums`、13–40px）—— 用来**比较**，必须等宽。
- 中文（400/700 两档、字距 0、行高 1.45）—— 用来**理解**。

三者混排时，永远按「标签 / 数据 / 说明」自上而下，不交叉。

### 一票退回

- 出现第二个「像强调」的颜色，或状态色被用在按钮上。
- 有任何 `border-radius` 不为 0。
- 切角与边框不同路径（切角处边框断开、或切角被 `overflow: hidden` 削掉一半）。
- 使用 `box-shadow` 做层级（阴影与切角互斥：`clip-path` 会裁掉阴影，硬加就是脏边）。
- 使用渐变（`linear-gradient` 做面、做按钮、做标题文字）。
- 数字没有 `font-variant-numeric: tabular-nums`，导致列对不齐。
- 状态自动降级，或告警需要 hover 才出现。
- 一屏超过 3 个动效同时在进行。

## 三、可调参数与设计变体

完整参数与四套预设的逐项数值，按第四节查表取用。骨架如下。

**八个旋钮**

| 旋钮 | 变量 | 取值域 | 默认 |
| --- | --- | --- | --- |
| 底色档位 | `--isx-bg` | ink-950 / ink-900 / ink-850 | `#0A0C0E` |
| 纸色档位 | `--isx-paper` | paper-000 / paper-100 | `#F2F4F3` |
| 信号色 | `--isx-signal` | 单值，不可增 | `#C8F04B` |
| 切角深度 | `--isx-cut` | 4 / 8 / 14 | 8px |
| 线宽 | `--isx-hairline` | 1px（唯一允许值） | 1px |
| 字距 | `--isx-track` | 0.10 / 0.14 / 0.18em | 0.14em |
| 行高（数据行） | `--isx-row` | 28 / 32 / 40 | 32px |
| 过渡时长 | `--isx-dur` | 90 / 140 / 220ms | 140ms |

**四套预设**

| 预设 | 底 / 纸 | 信号 | 行高 | 切角 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| `standard` | ink-900 / paper-000 | `#C8F04B` | 32px | 8px | 控制台、监控、日常管理台 |
| `cold-store` | paper-000 / ink-900（反相） | `#C8F04B` 填充块 | 36px | 8px | 档案、检索、报告、白底场景 |
| `site` | ink-950 / paper-000 | `#C8F04B` | 40px | 4px | 户外、平板、戴手套操作 |
| `night-shift` | ink-950 / paper-100 | `#A6C43E` | 32px | 8px | 夜间值守、低照度工位 |

**变体卡三行**（每次交付都写在说明最前面）

```text
preset: standard        # 四选一
density: mid            # compact(28) / mid(32) / loose(40)
dominant: industry      # research / industry —— 谁主导，判定见第四节第一行
```

**运行期契约（`assets/industrial.js`）**

全站只有一个全局：`window.ISX`，共 12 个键。

| 键 | 签名 | 说明 |
| --- | --- | --- |
| `ISX.setPreset(preset)` | `("standard"\|"cold-store"\|"site"\|"night-shift") => void` | 写 `data-preset` 到 `<html>` 并落 `localStorage`，切的是 Token 而不是样式表 |
| `ISX.getPreset()` | `() => string` | 读当前预设 |
| `ISX.setState(el, state)` | `(Element, "NOMINAL"\|"CAUTION"\|"INTERRUPT") => boolean` | **只升不降**：低态被忽略返回 `false`；只有 `acknowledge` 能降 |
| `ISX.acknowledge(el)` | `(Element) => void` | 人工确认，允许状态回落 |
| `ISX.stamp(format)` | `("iso"\|"time"\|"stamp") => string` | 三种时间戳格式，读数区统一用它 |
| `ISX.cutOf(name)` | `("chip"\|"card"\|"panel") => number` | 返回 4 / 8 / 14，`cutInner = cut − 1.414px` 由 CSS 变量承接 |
| 其余 6 个键 | — | 数字滚动、观察者挂载、动效降级、分区标题编号、告警流推送、Token 读写 |

状态机与 Token 都在这一个对象里，**没有 `ISX.init`**，脚本加载即完成挂载。

## 五、执行流程

1. **定主导方向**：三问打分（内容有时序吗？操作不可逆吗？环境暗吗？各记 0/1/2，和为 0–2 → industry，3–4 → research，5–6 → cold-store）。
2. **选预设**：从第三节的表里挑一个，写进变体卡，先不改任何数值。
3. **建 Token 层**：把 `assets/tokens.json` 里对应预设的值落到 CSS 自定义属性，全站一处定义，禁止就地写死。
4. **排版面骨架**：先只放 1px 线和留白三级（4 / 24 / 48），不填内容，检查分组是否成立。
5. **上切角**：按等级套 4 / 8 / 14，检查切角与边框同路径（放大到 400% 看断口）。
6. **填 HUD**：模块编号、分区标题、状态条。状态条长度必须来自真实数据，不能是装饰。
7. **上数据**：读数带单位、精度、时间戳；表格数字转等宽；超过 7 列就分两级表头。
8. **过动效**：只保留三种 —— 状态切换（140ms）、面板出现（220ms）、数值滚动（90ms × 步数）。其余删掉。
9. **过三态**：把 NOMINAL → CAUTION → INTERRUPT 各走一遍，确认颜色瞬切、几何有过渡、降级需 RESET。
10. **交付**：变体卡三行 + 下面第六节的清单逐条打勾。

## 六、交付检查清单

- [ ] 全站只有 1 个信号色；状态色（琥珀/赤）没有出现在按钮、选中态、链接上。
- [ ] 所有 `border-radius` 为 0；切角只切右上 + 左下两角，等级为 4 / 8 / 14px。
- [ ] 切角与 1px 边框同路径；放大 400% 时切角处边框不断开。
- [ ] 无 `box-shadow`、无 `linear-gradient`（含文字渐变与按钮渐变）。
- [ ] 间距只用 4 / 8 / 12 / 16 / 24 / 48 / 64 七档；段间距与区块间距保持 1:6:12 关系。
- [ ] 正文对比度 ≥ 4.5:1，次要信息 ≥ 3:1（给出两个实测值）。
- [ ] 所有数字列使用 `font-variant-numeric: tabular-nums`；列右对齐。
- [ ] 标签为全大写英文 + `font-stretch` 125% + 字距 0.14em；中文不设字距。
- [ ] 状态颜色变化为 0ms 瞬切，状态条宽度变化为 140ms。
- [ ] 状态只能单向升级；降级路径需要显式 RESET 控件。
- [ ] 同屏进行中的动效 ≤ 3 个；`prefers-reduced-motion: reduce` 下全部降为 0ms。
- [ ] 每个读数都带单位与精度；时间戳统一 `YYYY-MM-DD HH:MM:SS`（本地）或 `ISO 8601`（跨时区）。
- [ ] 变体卡三行（preset / density / dominant）写在交付说明最前面。
