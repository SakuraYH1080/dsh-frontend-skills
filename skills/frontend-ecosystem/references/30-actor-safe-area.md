# 30 · 角色、安全区与手势提交

> 只在"角色放哪""会不会挡内容""拖一下侧栏乱开"时读。构图美学交给 `frontend-anime-fusion`。

## 1. 四个位置，四种职责

| 位置 | 承担什么 | 放在哪 | 不可做 | 退出后的等价入口 |
| --- | --- | --- | --- | --- |
| 壁纸人物 | 世界与氛围 | 背景层构图，预留脸 / 道具 / 内容区 | 不做交互主体 | 无（纯装饰，可直接消失） |
| 吉祥物 | 场景入口 | 角落或工具带 | 不当唯一入口 | 工具栏按钮 + 菜单项 + 快捷键 |
| 会话头像 | 区分作者 | 锚定消息行 | 不参与布局节奏 | 文字署名 |
| 联动桌宠 | 可选动作 + 外部能力 | 独立层，声明 provider | 不静默接管手势 | 原按钮路径保留 |

**约束**：四者不能共用一个动画状态机。头像每帧都在，壁纸人物几乎不动，吉祥物只在被触发时动一下——混在一起就会出现"整页都在呼吸"。

## 2. provider 探测与让位

```text
provider = linked 的条件：
  服务在线 ∧ 开关打开 ∧ 接口存在 ∧ 目标可用
否则降级为 native（点击语义回退）
```

**必须随条件重判**：不是启动时判一次。服务掉线、目标被删、权限变化都要重新选。

### 2.1 一条真实的回归（v1.4.1 → 修复）【手册】

现象：拖动吉祥物时右栏反复闪烁。

原因链：
1. 每次移动都发 `onPull()`。
2. 联动门面固定交给 `linked` provider。
3. provider 在只能 native 时执行了"点击语义"回退。
4. 连续的移动信号被当作连续点击，反复触发侧栏开合。

修复两条：
- 门面按**当前模式**选 provider，而不是启动时锁定。
- 已进入 linked provider 的手势，即便途中目标失效，也只返回降级结果，**禁止触发点击回退**；开合仍归宿主手势代码。

**可迁移约束**：连续信号不得触发一次性动作；降级路径也不得改变手势语义。

迁移到别的项目：
- 拖动音量滑块 → 每帧预览，持久化走有节制的通道。
- 拖地图 → 保持跟手，提交位置放在确定之后（`pointerup` 或 `moveend`）。

## 3. 拉绳：预览 / 提交 / 取消三分

### 3.1 数值【源码】

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `ROPE_PREVIEW_START` | 32 px | 下拉超过此值开始跟手预览 |
| `ROPE_OPEN_THRESHOLD` | 96 px | 松手时判定开 / 合的阈值 |
| `MASCOT_DRAG_SLOP_PX` | 6 px | 判定"是拖动而不是点击"的死区 |
| `ROPE_EDGE_INSET` / `ROPE_VIEW_MARGIN` | 8 px | 贴边内缩与视图留白 |
| `ROPE_SCALE_MIN / MAX / STEP` | 0.5 / 2.5 / 0.05 | 缩放范围与步进 |
| `ROPE_FALLBACK_SIZE` | 52 × 57 | 尺寸读取失败时的兜底 |

**出入记录**：手册写死区 3 CSS px，源码为 6。以 6 为默认；3 仅作为"更灵敏"备选，需实测误触。

### 3.2 状态表

| 状态 | 进入 | 画面 | 副作用 | 离开 |
| --- | --- | --- | --- | --- |
| idle | 初始 / 复位 | 角色停在锚点 | 无 | pointerdown |
| armed | pointerdown + setPointerCapture | 不变 | 记录起点、捕获指针 | 位移 > slop 或 pointerup |
| previewing | 位移 > 32px | 角色跟随，抽屉跟随比例 | **只更新位置，不改开合** | 松手 / 取消 |
| committing | 松手且位移 ≥ 96px | 过渡到已提交状态 | 一次开合（向下开、向上关各一次） | 过渡结束 → idle |
| cancelling | pointercancel / Esc / 失去捕获 | 回弹到锚点 | 清预览、归还捕获、保留原开合 | 复位 → idle |
| clicked | 松手但位移 < slop | 触发点击语义 | 一次 | idle |

**硬约束**：
- `previewing` 期间不得写持久化，不得路由跳转，不得发业务请求。
- `committing` 必须幂等：重复松手事件只生效一次。
- `cancelling` 结束后，开合状态**保持按下前的样子**，不能顺手"补一次开"。

### 3.3 键盘等价

`Enter` / `Space` 走与点击完全相同的动作路径（同一个函数，不是复制一份）。焦点可见，`aria-expanded` 与实际开合同步。

## 4. 安全区图

每个场景一张，四个矩形：

```text
┌──────────────────────────────┐
│  [A] 脸与道具保护框            │
│         ┌──────────────┐      │
│         │ [B] 正文盒    │      │
│         └──────────────┘      │
│  [C] 点击热区     [D] 面板边线 │
└──────────────────────────────┘
```

| 区 | 规则 |
| --- | --- |
| A 脸 / 道具 | 任何面板、文字、按钮都不得覆盖；裁切时不得切到眼与嘴 |
| B 正文盒 | 角色可贴近边缘，不得进入盒内；背景在此区必须低细节 |
| C 点击热区 | ≥ 44×44 px；不得与拖动死区重叠到无法点击 |
| D 面板边线 | 角色"从面板后探出"时，允许越过的最大边界 |

**宽窄屏**：宽屏先排主体与面板并置；窄屏重排观看顺序（先角色还是先内容，要明确选一个），而不是把两者挤在一起缩。

**前后两片角色资产**（如"人 + 飘带"）共用一个锚点与缩放值；装饰片 `pointer-events: none`。

## 5. 等价入口矩阵

| 功能 | 指针 | 键盘 | 角色隐藏后 | 角色加载失败 |
| --- | --- | --- | --- | --- |
| 打开设置 | 点吉祥物 / 工具栏 | Tab → Enter | 工具栏按钮 | 工具栏按钮 |
| 切换场景 | 设置面板 | 同上 | 同上 | 同上 |
| 关掉角色 | 设置项 | 同上 | 已经是关闭态 | 显示"角色不可用" |

**判据**：把角色整层删掉（`display:none`），矩阵右侧两列仍然全部可达，才算通过。

## 6. 动效与代价

- 呼吸：±2px / 约 4s，幅度再大就开始抢注意力。
- hover 视线跟随、点击换表情：属于事件效果，结束后释放绘制循环。
- 减少动态时：静态构图 + 完整功能按钮，不是"整个角色消失"。
- 移动端：触摸拖动与页面滚动会打架，必须在角色容器上明确 `touch-action`。

## 7. 本层验收点

- [ ] 四类角色各有独立状态，不共用一个动画状态机。
- [ ] provider 每次条件变化都重判；手势中途失效只降级、不改语义。
- [ ] 拖动过程零开合、零保存、零跳转。
- [ ] 松手提交幂等；取消后开合状态保持原样。
- [ ] Enter / Space 与点击走同一函数。
- [ ] 桌面与窄屏各有一张安全区图；脸与正文盒无遮挡。
- [ ] 删掉角色层后，所有功能仍可达。
- [ ] 44×44 px 触控目标；`touch-action` 明确。
