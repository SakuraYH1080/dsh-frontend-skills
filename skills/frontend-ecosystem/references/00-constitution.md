# 00 · 宪法：边界、五层职责与证据

> 这一份只在两种时候读：第一次接触本 skill；或者团队对"这该归谁管"吵起来了。

## 1. 这个 skill 管什么

管**层与层之间**的四件事：职责、时序、让位、退出。

| 问题 | 归本 skill | 归专项 skill |
| --- | --- | --- |
| 玻璃该不该出现在这个面上、出现多强 | 是（承载分级） | 参数配方归 `frontend-liquid-glass` |
| 正文压在这块玻璃上读不清 | 是（承载方式与底色的取舍） | 只调材质时归玻璃 skill |
| 粒子层何时启用、何时降级、何时停 | 是（预算与让位） | 生成、寿命、渲染归 `frontend-particles` |
| 立绘与面板谁压谁、脸会不会被挡 | 是（安全区与遮挡顺序） | 构图美学归 `frontend-anime-fusion` |
| 换背景闪黑 / 旧请求覆盖新请求 | 是 | — |
| 设置刷新丢失 / 预设清空资产 | 是 | — |
| 页面节高、字号、留白 | 不是 | `frontend-apple-minimal`、`frontend-taste-base` |
| 工业 / 科幻视觉语言 | 不是 | `frontend-industrial-sci-fi` |

判据一句话：**"这一层要不要存在、什么时候存在"归这里；"这一层怎么做才好看"归专项。**

### 2.2 v1.4.2 源码事实表（本机安装产物）

安装根：`<dshHome>/profiles/desktop/node_modules/`。以下版本均为 **1.4.2**：主包 `dsh-plugin-wallpaper-engine`，以及 `about-notice` / `fonts` / `fx` / `glass` / `mascot-avatar` / `media-bridge` / `parallax` / `pet-link` 八个子包。安装形态只有 `lib/` 编译产物，没有 `src/`——所以本 skill 只引用**编译后仍可见**的常量与表达式。

| 事实 | 位置 | 值 |
| --- | --- | --- |
| 模糊默认值 | `dsh-plugin-wallpaper-engine/lib/settings-schema.js` | `blur: 16`（默认），值域 0–60 |
| 玻璃透明度默认 | 同上 | `glassAlpha: 20`（默认），值域 0–100（百分比） |
| 玻璃保真度默认 | 同上 | `glassFidelity: 100`（默认），值域 0–100 |
| 边框强度默认 | 同上 | `border: 0.35`，值域 0–1 |
| 旧刻度迁移 | 同上 | `rescale('glassAlpha', 100 / 60, 100)`——旧版 0–60 刻度乘 5/3 迁到 0–100 |
| 透明度→覆盖度映射 | `dsh-plugin-wallpaper-engine-glass/lib/client.glass.js` | `Math.max(0.10, 0.25 - (selection.glassAlpha / 100) * 0.15)` |
| 可读性地板（浅） | 同上 | `READABILITY_FLOOR = 0.45` |
| 可读性地板（深） | 同上 | `READABILITY_FLOOR_DARK = 0.59` |
| 最坏情况标注 | 同上（注释） | 4.63:1 |
| 暗主题衰减 | 同上 | 玻璃 alpha 再乘 0.4 |
| 各面独立变量 | 同上 | `settings-window` / `thinking-trigger` / `left-sidebar` / `titlebar` / `floaters` 各有变量，但曲线同形 |
| 拉绳开合阈值 | `dsh-plugin-wallpaper-engine/lib/client.js` | `ROPE_OPEN_THRESHOLD = 96` |
| 拉绳预览起点 | 同上 | `ROPE_PREVIEW_START = 32` |
| 拖动死区 | 同上 | `MASCOT_DRAG_SLOP_PX = 6`（CSS px） |
| 边缘内缩 / 视图留白 | 同上 | `ROPE_EDGE_INSET = 8`、`ROPE_VIEW_MARGIN = 8` |
| 兜底尺寸 | 同上 | `ROPE_FALLBACK_SIZE = { w: 52, h: 57 }` |
| 缩放范围 | 同上 | `0.5` – `2.5`，步进 `0.05` |
| 持久化合并窗口 | 同上 | `setTimeout(flushPersist, 200)`；字体设置同样 200ms |
| 隐藏页暂停防抖 | 同上 | `HIDDEN_PAUSE_DEBOUNCE_MS = 1200` |
| iframe 沙箱 | 同上 | `setAttribute("sandbox", "allow-scripts")`——刻意不给 `allow-same-origin` |
| 预设 schema tag | `settings-schema.js` | `dsh-we/profile-preset@1`；墓碑 `dsh-we/glass-preset-tombstone@1` |
| 面级模式默认 | 同上 | `glassMode` 每面默认 `inherit`（`GLASS_MODE_DEFAULTS`），另有 `glassSurfacePolicy` 面→策略映射 |

**一处必须记录的出入**：手册正文写"坐标抖动死区 3 CSS px"，源码是 `MASCOT_DRAG_SLOP_PX = 6`。结论：6 是默认值；3 只能作为"更灵敏"的可选档，并且要在真机上重测误触率。

**仅存在于手册、本机产物未直接读到**（引用时必须标【手册】）：首帧交接的具体实现、音频门、provider 门面、写入差分批次。本机只能确认 200ms 合并窗口与 1200ms 防抖常量存在。

## 3. 五层职责表

每层必须填满六格，缺一格就不算定义完成。

| 层 | 职责 | 最低可用形态（全关时） | 启用条件 | 让位条件 | 退出后留下 | 恢复动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 场景 | 背景构图、光线方向、动势 | 静态图或主题纯色 | 有可用素材且未命中省电 / 减少动态 | 用户暂停、页面隐藏、解码失败 | 底色与对比关系不变 | 重算可见性与播放意图 |
| 表面 | 透光、边缘、层级、文字承载 | 宿主原生表面或实色底 | 该面被声明为可玻璃化且有阅读余量 | 正文对比不足、祖先形成 backdrop root、软件渲染 | 层级可辨、正文对比不降 | 恢复时重算覆盖度与对比 |
| 角色 | 身份提示、陪伴、进入设置 | 头像按钮 + 文字 | 素材可用且用户未关 | 与任务区冲突、手势进行中降级、provider 不可用 | 工具栏 / 菜单入口 | 按条件重判 provider |
| 氛围 | 指针反馈、拖尾、深度 | 无持续动画 | 输入事件发生且未减少动态 | 空闲、页面隐藏、帧预算超限 | 控件自带的反馈 | 下一次输入事件重启 |
| 业务界面 | 对话、搜索、阅读、输入、焦点 | 同一套语义控件与业务数据 | 始终 | 只在模态 / 全屏任务时提升层级 | 完全不受其他层开关影响 | 无（它不该被关掉） |

**读法**：这五层里唯一"永远在"的是业务界面。其余四层的默认状态都应该是"可以不在"。

## 4. 四格独立性

| 组合 | 期望结果 | 检查点 |
| --- | --- | --- |
| 有场景 + 开玻璃 | 背景与玻璃协作，阅读面稳定 | 正文对比达标；玻璃边缘与环境色关系成立 |
| 有场景 + 关玻璃 | 宿主表面回原生，背景仍在 | 层级不塌；原生表面不发灰 |
| 无场景 + 开玻璃 | 玻璃对宿主底面生效 | 底面为纯色时不出现"脏灰" |
| 无场景 + 关玻璃 | 原生界面可独立完成任务 | 全增强关闭验收通过 |

**三个范围要分开说**，不能混成一句"关掉玻璃"：
- 停用玻璃子包（整体）
- 某几个面保留原生（局部）
- 对话内容选原生档（内容级）

## 5. 双路径收口

```text
素材路径：素材目录 → 库索引 → 选择与准备 → 实时 / 视频 / 静态 / 纯色
偏好路径：用户偏好 → 校验与迁移 → 有效配置 → 场景 / 表面 / 角色 / 氛围
                                    ↑
                              两条路径在此相遇
                       宿主保存 + 回传可见反馈 / 失败原因 / 重试入口
```

**权威源**：宿主持久化文件。浏览器存储只是缓存与迁移入口。跨端口重启以宿主文件为准。

## 6. 模块接入合同（六字段）

任何增强模块挂进来，都要能回答六句话：

| 字段 | 要回答 | 反例 |
| --- | --- | --- |
| 输入 | 我读哪些状态、哪些是外部给的 | 直接读别人的 DOM |
| 挂载 | 我插入到哪个容器、声明了哪些样式节点 | 往 body 乱插 style |
| 同步 | 我如何跟随状态变化、频率多少 | 每帧全量重算 |
| 让位 | 什么条件下我退到最低形态 | 死占着 z-index |
| 销毁 | 我移除哪些节点、监听、定时器 | 留一堆孤儿 style |
| 持久化 | 我写哪些键、谁合并、冲突怎么办 | 自己另存一份孤本 |

**判据**：每次更新都要能回答"我拥有什么、它今天还在不在、退出时怎样还原"。

## 7. 三条常见误判（见 `50-acceptance.md` 详版）

1. 玻璃不清楚就加模糊——通常该改的是底色覆盖与文字色，以及这块面的材质分区。
2. 角色很热闹但只剩它能开设置——入口必须是等价多路，而不是"更明显地只有一条"。
3. 切换闪黑就延长淡入——先记录新画面第一帧何时真正可用，再决定交接方式。

## 8. 与兄弟技能的交接口径

- 交给 `frontend-liquid-glass` 时，本 skill 给出：哪一面、承载分级、目标对比度、可用预算。对方给回：材质参数与降级方案。
- 交给 `frontend-particles` 时，本 skill 给出：氛围层的启用条件、帧预算上限、退出方式。对方给回：渲染路线与降级档。
- 交给 `frontend-anime-fusion` 时，本 skill 给出：安全区矩形、遮挡顺序、窄屏重排规则。对方给回：构图与素材处理。
