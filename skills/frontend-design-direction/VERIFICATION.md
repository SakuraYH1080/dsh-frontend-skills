## 2. 场景一：录音档案首页改版

### 2.1 路由判断

改首页会迫使详情页与窄屏一起改（字段槽位、术语、比较方式都要跟着动），命中 `SKILL.md` §0 的判据「改完这件事会不会迫使另一页也改」。走整体技能。

| 技能 | 是否加载 | 理由 |
| --- | --- | --- |
| `frontend-design-direction` | 加载，主导 | 要重排标题/列表/详情分工，并定跨页规则 |
| `frontend-taste-base` | 不加载 | 本轮不调节高、不调动效额度；文案声口由馆藏原有名称决定 |
| `frontend-liquid-glass` | 不加载 | 没有玻璃表面需求 |
| `frontend-apple-minimal` | 不加载 | 档案检索不是产品叙事页，不留白叙事 |
| `frontend-industrial-sci-fi` | 不加载 | 不是设备/读数界面，硬套切角会与纸本图版冲突 |
| `frontend-particles` / `frontend-anime-fusion` / `frontend-ecosystem` | 不加载 | 无粒子、无角色、无多层增强 |

### 2.2 折叠态字段（按 §2 算法）

任务句：拿曲名来的读者，要认出这是班卓琴录音、报得出目录号、判断得出地点能不能当已确认资料引用。

| 字段 | 折叠态 | 展开态 | 依据 |
| --- | --- | --- | --- |
| 录音日期 | 显示 | 显示 | 目录按时间组织，是本页排序依据 |
| 演奏形式（班卓琴独奏 / 乐队演奏） | 显示 | 显示 | 同曲两个版本靠它区分，是第一眼的分辨字段 |
| 演出人员 | 显示 | 显示 | 区分同名录音的第二线索 |
| 目录号（Victor 3045 / 306） | 显示 | 显示 | 读者手里的线索，也是查档案的凭据 |
| 母版号 / 录音次号 | 收起 | 显示 | 核对具体录制才需要 |
| 唱片直径 | 收起 | 显示 | 主图已用比例表达，文字只在核对时给数值 |
| 地点与确定性（Camden, New Jersey（未确认）） | 收起，但曲名旁给一次「地点未确认」提示 | 显示并附回查链接 | 读者可能引用，折叠态就要知道「这条不能当已确认资料」 |
| 馆藏链接 | 收起 | 显示 | 紧贴记录，不另开页 |

反例：通用稿把曲名放在折叠行，演奏形式与目录号收进详情，读者必须展开才能分辨版本——同一批内容，槽位换了语义就丢了。判定方法是拿掉产品名、把两条记录折叠只看一行，问「能不能说出这是哪一次录音」。

## 3. 场景二：只修聊天框玻璃对比度

### 3.1 路由判断

改完不影响别的页面，边界清楚，命中 §0 的「只改一个维度」。直接进材质专项，整体技能不介入。

| 技能 | 是否加载 | 理由 |
| --- | --- | --- |
| `frontend-liquid-glass` | 加载，唯一执行方 | 只处理材质、参数与可读性回退 |
| `frontend-design-direction` | 不加载 | 不涉及版式、信息结构与他页一致性 |

### 3.2 检查方法（亮底与暗底各跑一遍）

1. 定两端取样：最亮背衬（消息区 `#f7f7f8`、浅壁纸 `#e8e2d6`）与最暗背衬（暗消息区 `#14161a`、深壁纸 `#2b3138`）。
2. 算合成底色：`composite = tint × α + bg × (1 − α)`，逐通道四舍五入。
3. 算相对亮度：`c/255` 后 `c ≤ 0.04045 ? c/12.92 : ((c+0.055)/1.055)^2.4`，`L = 0.2126R + 0.7152G + 0.0722B`。
4. 算对比度：`(L1+0.05)/(L2+0.05)`。正文 ≥ 4.5:1，大字与非文字 ≥ 3:1。
5. 两端都过才算过；只是一端过，说明承载层不够，要加 scrim 或换实心底。

复跑：`node scripts/contrast.mjs "#ffffff" 0.55 "#14161a" "#1a1d22"`，不带参数输出整张对照表。

### 3.3 实测（白 tint 气泡，文字 `#1a1d22`）

| α | 亮底 `#f7f7f8` | 暗底 `#14161a` | 判定 |
| --- | --- | --- | --- |
| 0.45 | `#fbfbfb` 16.33:1 | `#7e7f81` 4.22:1 | 暗底不过 |
| 0.55 | `#fbfbfc` 16.34:1 | `#959698` 5.71:1 | 两端过 |
| 0.65 | `#fcfcfd` 16.48:1 | `#adadaf` 7.54:1 | 两端过 |

反解最小 α（文字 `#1a1d22`、目标 4.5:1）：亮底 0.30 已过，暗底需 0.47。

### 3.4 实测（深 tint `#0c1017` 气泡，文字 `#f2f4f8`）

| α | 亮底 `#f7f7f8` | 暗底 `#14161a` | 判定 |
| --- | --- | --- | --- |
| 0.45 | `#8d8f93` 2.94:1 | `#101319` 16.89:1 | 亮底严重不过 |
| 0.55 | `#76787c` 4.02:1 | `#101318` 16.90:1 | 亮底仍不过 |
| 0.65 | `#5e6166` 5.65:1 | `#0f1218` 17.03:1 | 两端过 |

反解最小 α：亮底 0.585，暗底 0.30。

### 3.5 边界与焦点（3:1 一档）

白玻璃 α0.55 叠暗底 `#959698` 上，边框 `#8a8f99` 只有 1.10:1；亮底 `#fbfbfc` 上 3.14:1。深玻璃 α0.78 的 `#404349` 上，焦点环 `#2f6df6` 只有 2.19:1。

结论：半透明白边在暗底上等于没有边界；焦点环不能写死一个蓝，要按主题换成能对当前合成底 ≥3:1 的色值，或加 1px 内描边。

### 3.6 修法与选择

- 优先：气泡内容加不透明承载层（scrim），玻璃只做外沿，正文对比度由承载体保证。
- 次选：按主题分两套 token——亮主题白 tint α ≥ 0.55，暗主题深 tint α ≥ 0.65；只为美观把 α 压到 0.45 会在暗底破线。
- 回退：`prefers-reduced-transparency: reduce` 或不支持 `backdrop-filter` 时切 L3 实心（α 0.98），保留边框与阴影。
- 不要把透明度当信息通道（发送状态、未读）——改位置、尺寸或颜色。

## 4. 场景三：苹果式产品页 + 局部玻璃

### 4.1 路由判断

要同时定叙事、字阶与一处材质，且三个决定会互相牵制（玻璃要不要压住正文、回退后版面是否塌）。走整体技能编排，专项各管一段。

| 技能 | 是否加载 | 决定范围 |
| --- | --- | --- |
| `frontend-design-direction` | 加载，编排与裁决 | 首屏读什么、section 顺序、跨页术语、台账 |
| `frontend-apple-minimal` | 加载 | 信息三层、8pt 网格、节间距 64/96/128/160、字阶 1.25/1.333、600px 栏宽、动效 120/240/400/650ms、三断点 |
| `frontend-liquid-glass` | 加载 | 只负责指定那一条表面的 tint/blur/border、层数 ≤3、L0–L3 降级、对比度阈值 |
| `frontend-taste-base` | 按需抽用 | 只做文案声口走查与「这一节是否该存在」，不定叙事顺序 |
| `frontend-particles` / `frontend-anime-fusion` / `frontend-ecosystem` | 不加载 | 没有粒子、角色与多层场景交接 |

### 4.2 决定台账

| 决定 | 定稿方 | 范围 |
| --- | --- | --- |
| 首屏说什么、几屏讲完 | apple-minimal | hero 结构、section 编排 |
| 字阶、栏宽、节高 | apple-minimal | 全页正文与标题 |
| 玻璃用在哪一条带 | design-direction | 只授权一条表面，其余保持实心 |
| 玻璃参数与回退 | liquid-glass | tint/blur/border/层数/降级 |
| 正文落在玻璃上还是玻璃外 | design-direction 裁决 | 以可读性为硬线 |
| 术语称呼与跨页一致性 | design-direction | 全站同一对象同一叫法 |
| 识别细节（一处） | 项目自定 | 只允许一处，且能从内容解释 |

### 4.3 冲突裁决三条

1. 字阶与玻璃冲突时，字阶不动。玻璃的模糊与折射只能改变它自己那一层的观感，不能要求把 16px 正文提到 18px 去凑对比度；做不到就让正文移出玻璃。
2. 美观与可读性冲突时，可读性优先。玻璃可以退到 L3 实心，产品页必须接受「回退后是一条实心带」这一形态，不允许为了透明感把对比度压到 4.5 以下。
3. 动效归叙事方。玻璃的形变动效只在进入/离开视口时发生，时长跟 apple-minimal 的四段阶梯，不另立一套缓动。
