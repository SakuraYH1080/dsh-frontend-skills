# 主导语言、Token 与识别细节

## 一、从内容找语法

不从风格名开始。从三个来源找：

1. **对象形态**：圆、方、比例、材料、刻度、编号位置。
2. **记录方式**：日期、编号、版本、图注、来源、状态词。
3. **使用场景**：查、比、引用、试听、操作、监控。

每个来源至少提取一条可复用规则。提取不出来，说明内容还没看够。

## 二、规则表

写 5–7 条，每条回答一个未来问题：

| 维度 | 要回答的问题 | 《针迹》的答案 |
| --- | --- | --- |
| 字体分工 | 什么字用来定题、对照、阅读？ | 宋体定题；等宽对照日期与编号；无衬线正文与控件 |
| 颜色角色 | 每种颜色表示什么？ | 纸底阅读；墨色主文字；锈红只给查找/链接/焦点 |
| 表面 | 哪些面可以有纹理，哪些必须平？ | 主图深图版底；正文平整纸底；线纹不进正文 |
| 密度 | 首页、列表、详情谁疏谁密？ | 首页疏、目录密、详情更密；字段名三处一致 |
| 动效 | 动效解释什么？ | 展开/收起解释层级；不做无关漂浮 |
| 不确定性 | 未确认/缺失怎么写？ | "未确认"紧跟地点；不藏在详情末尾 |
| 边界 | 分组线、卡片、留白怎么用？ | 版本行用贯穿分组线；不靠卡片堆叠 |

规则必须能延续到第二页。只在首屏成立的，是构图。

## 三、Token 三层

| 层 | 放什么 | 例 |
| --- | --- | --- |
| 基础值 | 原始色、字族、间距刻度 | `--paper: #f5f0e5`、`--ink: #242820`、`--rust: #9b3824` |
| 语义样式 | 用途命名，不绑具体页面 | `--surface-reading`、`--text-primary`、`--text-muted`、`--link`、`--focus`、`--control-border` |
| 组件 | 只取对应语义，不直接取基础值 | 记录行取 `--text-primary` / `--rule`；按钮取 `--control-border` |

好处：新增页面只选语义；换肤只改基础值；深色/强制颜色模式有明确的映射点。

错误做法：

- 组件里直接写 `#9b3824`，换主题时漏改；
- 一个语义名对应两种用途（链接色同时当警告色）；
- 先做组件再补语义，最后两套值并存。

## 四、识别细节

### 四个条件

1. 有依据：真实字段、真实比例、真实材料，能说出出处。
2. 会重复：至少两个位置出现，形成可跟随的线索。
3. 可撤下：拿掉后任务仍完成。
4. 有说明：图注、来源、比例说明；示意图必须写明。

### 两个测试

- **遮标测试**：遮住 logo 与产品名，是否还能认出项目？
- **撤细节测试**：拿掉细节，从首屏到结果到详情，路径是否仍成立？

### 放置

- 放在用户本来就会比较的地方（版本之间、记录与来源之间）。
- 不承担唯一编码：文字与排布必须能独立区分记录。
- 一个项目只留一处。第二页复用后若变成纯装饰，撤下。
- 动效型细节要有静态形态；减少动态时仍能表达同一件事。

### 《针迹》的细节

两张唱片图版按 10:7 同比例绘制，圆心同一水平线；目录号在图版、列表、详情重复；图注写"据馆藏尺寸字段绘制的示意图"。

它成立的原因：

- 尺寸是真实字段，读者确实会比较 10 英寸与 7 英寸；
- 同一目录号把图、列表、来源串起来；
- 撤掉图版，标题、筛选、详情仍然各司其职；
- 有图注，不冒充实物照片。

## 五、跨页延续

同一状态跨页时，固定三件事：

1. 术语不变：列表叫"录音日期"，详情也叫"录音日期"。
2. 状态不变：未确认在列表和详情都标，不因空间小而消失。
3. 操作不变：展开、收起、查档案、清除筛选，在各页行为一致。

可变的是密度与构图：首页可以并列，列表可以分行，窄屏可以逐项读。可变的是排布，不是语义。

## 六、移动端顺序

窄屏不是把桌面缩小，是重新排阅读顺序：

- 先给身份（曲名/编号），再给差异字段，再给核对字段，最后给出处。
- 长人名、长地名先换行，不缩字号到不可读。
- "未确认"紧跟地点，不因为换行被甩到下一段。
- 声音/原件入口用编号标识，避免"播放"一排按钮分不清是哪条。
- 触控目标不小于 44px；焦点可见。

## 七、个性从哪里来

按可靠性排序：

1. 真实对象名与术语（不是"精选内容"）；
2. 真实比例与字段（直径、刻度、编号结构）；
3. 真实状态与恢复语义（未确认、过期、无匹配）；
4. 材料与工艺（纸、墨、金属、图版）；
5. 入口线索（用户带着什么来）；
6. 一处可撤下的识别细节。

不可靠的来源：风格形容词、竞品截图拼接、无出处的纹理、只出现一次的动效。

## 八、去 AI 味的检查

| 检查 | 通过 | 失败 |
| --- | --- | --- |
| 拿掉产品名 | 仍能看出行业、对象、任务 | 换成任何行业都成立 |
| 标题 | 指向具体对象 | "精选""发现""未来" |
| 区块层级 | 有主次、有疏密 | 所有块同标题同容器 |
| 空状态 | 说清哪个筛选导致、下一步做什么 | 一律"暂无内容" |
| 文案 | 用项目术语、具体名词 | "赋能""沉浸""全新体验" |
| 细节 | 能从内容解释 | 无出处装饰 |

记录问题时写成"哪位用户在什么状态下看错了什么"，不写"感觉不对"。
