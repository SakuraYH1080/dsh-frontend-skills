# 案例：《针迹》录音档案

源文件：`frontend-design-master/第八章_配套/针迹录音档案.html`（单文件、离线、无网络请求）。
同一份 HTML 用 `body[data-view="archive"|"generic"]` 切换两版，用来比较"同一批内容、不同分工"。

## 一、材料与约束

两条馆藏，全部字段以原页为准：

| 字段 | Victor 3045 | Victor 306 |
| --- | --- | --- |
| 曲名 | Banjo Solo | The Stars and Stripes Forever |
| 演奏形式 | 班卓琴独奏 | 乐队演奏 |
| 演出人员 | Vess L. Ossman | Sousa's Band |
| 指挥 | — | Arthur Pryor |
| 录音日期 | 1901-01-21 | 1903-08-14 |
| 目录号 | Victor 3045 | Victor 306 |
| 母版号 | [Pre-matrix B-]3045 | A-241 |
| 录音次号 | take 1 | take 2 |
| 直径 | 10 英寸 | 7 英寸 |
| 地点 | Camden, New Jersey（未确认） | 未列 |

约束：

- 只做离线索引，不内嵌音频，不请求网络；
- 日期一律指录音日期，不写成发行日期；
- 目录号查发行品，母版号/次号核对具体录制，两者不混；
- 地点保留确定性，"未确认"不能被省略；
- 唱片图版是示意图，不是实物照片。

## 二、任务句与完成证据

> 让只知道曲名的听众，在首页和目录里认出班卓琴录音、读出目录号，并判断地点能否当作已确认资料引用。

完成证据：能说出"Victor 3045，Camden, New Jersey，地点未确认"，并指出回查处（展开后的馆藏链接）。

三类用户带的线索不同：

- 知道曲名 → 首屏给曲名与两种演奏形式，同曲记录编在一起；
- 拿着唱片编号 → 搜索与编号提前，目录按厂牌/编号组织；
- 想按时间浏览 → 目录按录音日期组织，演奏形式与人员进折叠行。

参考实现选的是第一类，同时在页顶保留跳到目录的入口。

## 三、四层内容

| 层 | 内容 | 用户的问题 |
| --- | --- | --- |
| 第一眼 | 曲名、两种演奏形式、进入目录 | 这是不是我要找的作品？有哪些可比较版本？ |
| 扫读比较 | 录音日期、演奏形式、演出人员、目录号 | 这一条和那一条差在哪？ |
| 核对 | 母版号、录音次号、直径、地点与确定性、馆藏链接 | 我能不能引用？依据在哪？ |
| 恢复 | 结果数、无匹配说明、清除筛选 | 没找到时怎么办？ |

## 四、两版骨架

| | 通用稿（generic） | 档案稿（archive） |
| --- | --- | --- |
| 首屏 | 居中 hero、英文曲名、两张等权卡片 | 具体曲名、右侧 10:7 图版、进入目录 |
| 折叠行 | 英文曲名 + 演奏者 | 日期 + 演奏形式 + 演出人员 + 目录号 + 查档案 |
| 目录 | 卡片网格，入口集中 | 沿录音日期组织，版本行用分组线连接 |
| 详情 | 形式、编号、母版号、次号、直径、地点 | 同左，但入口紧贴记录 |
| 适合 | 题材各异的选集 | 同曲多版本、需要引用编号的档案 |

关键差别不在配色，而在折叠行第一个强项放什么：

- 通用稿放英文曲名（作品身份），两条记录的强项几乎一样；
- 档案稿放"班卓琴独奏/乐队演奏"（版本差异），曲名已由页首标题承担。

同一批内容，通用稿要筛选或展开才能完成第一次辨认；档案稿折叠态即可。

## 五、折叠态字段

参考实现的折叠行：

```html
<time>1901-01-21</time>
<span class="record-name">
  <strong class="archive-only">班卓琴独奏</strong>
  <span class="artist">Vess L. Ossman</span>
</span>
<span class="catalog-no archive-only">目录号 <b>Victor 3045</b></span>
<span class="disclosure">查档案</span>
```

四个位置各司其职：

1. 日期：排序与时间定位；
2. 演奏形式 + 演出人员：区分版本；
3. 目录号：报给他人、查发行品；
4. 查档案：告诉用户这里可以展开，不用另设按钮。

详情里保留：

- 演奏形式（重复一次，便于展开后独立阅读）；
- 唱片目录号、母版号、录音次号；
- 唱片直径；
- 录音地点 + "未确认"（3045）；306 没有地点字段，版式不能因此塌；
- 指挥（306）；
- 馆藏与试听链接。

## 六、主导语言

旧唱片图版语法，六条规则：

| 维度 | 规则 |
| --- | --- |
| 字体 | 大号宋体定题；等宽字对照日期与目录号；正文/控件用清楚无衬线 |
| 颜色 | 纸底与墨色承载阅读；锈红只给查找、链接、键盘焦点 |
| 表面 | 主图可用更深图版底；正文保持平整纸底；唱片线纹不进正文 |
| 密度 | 首页疏、目录密、详情更密；同一字段三处同名 |
| 动效 | 展开/收起解释层级；不做与对象无关的漂浮 |
| 确定性 | "未确认"紧跟地点；不藏到详情末尾 |

Token 三层：

```css
:root {
  /* 基础值 */
  --paper: #f5f0e5;
  --ink: #242820;
  --muted-ink: #53584e;
  --rust: #9b3824;
  --rule: #827769;
  --wash: #ece5d7;

  /* 语义样式 */
  --surface-reading: var(--paper);
  --text-primary: var(--ink);
  --text-muted: var(--muted-ink);
  --link: var(--rust);
  --focus: var(--rust);
  --control-border: var(--rule);
}
```

组件只取语义变量；新增页面不直接写十六进制值。

## 七、识别细节

唱片直径：

- 两张图版按同一比例绘制，直径比 10:7；
- 圆心在同一水平线，读者能直接看出大小差；
- 图版内保留目录号，与列表、详情重复；
- 图注写明"据馆藏尺寸字段绘制的示意图"。

为什么选它：

- 尺寸是读者真的会比较的差异（10 英寸与 7 英寸）；
- 它能跟着记录走：图上的编号与列表里的编号是同一个；
- 撤掉图版，标题、筛选、详情仍然成立，所以它是细节，不是结构；
- 有图注，不冒充实物照片。

不选什么：

- 不做无出处的旧纸纹理；
- 不做只在首屏出现一次的 3D 唱片；
- 不让图版承担"哪条是班卓琴"的唯一线索，文字必须能独立说明。

## 八、移动端顺序（390px）

1. 页首标题与一句说明；
2. 主图移到说明之后，图注紧跟；
3. 页首提供"跳到版本目录"；
4. 每条记录按"日期 → 演奏形式 → 演出人员 → 目录号"读；
5. 长人名、长地名折行，不缩到不可读；
6. "未确认"跟在地点后，不被换行甩走；
7. 声音/馆藏入口以目录号标识，避免一排"播放"分不清。

## 十一、可迁移结论

1. 同曲多版本，曲名只写一次；版本差异字段必须进折叠态。
2. 需要引用的事实放详情，但入口要紧贴记录，不要让人跳转后失去上下文。
3. 识别细节要能跟着记录走，编号在三处一致，读者才能在图、列表、来源之间定位。
4. 空字段要用版式接住：306 没有地点，详情不能因此错位。
5. 两版共用交互（筛选、展开、来源链接），切换时保留已展开记录与焦点，比较才公平。
