# 30 · 面板：与角色抢地盘的规矩

## 1. 面板不是容器，是插进空间的板子

面板必须让人相信它**占据一个位置**。三条同时成立才信：

| 证据 | 做法 | 反例 |
| --- | --- | --- |
| 有厚度 | 1px 亮边（受光侧）+ 0 1px 0 暗边（背光侧），不描四边 | 四面均匀 1px 边框 → 像贴纸 |
| 有投影方向 | box-shadow: 0 12px 32px -8px rgba(0,0,0,.35)，方向与背景光一致 | 投影四散或没有投影 → 浮不起来 |
| 有接地 | 面板底边与角色裁切线对齐（误差不超过 4px），或明确悬空不小于 32px | 差 12px → 看起来像没对齐的 bug |

**判据**：遮住角色只看面板，能说出光从哪来、板子离地多高。

## 2. 遮挡顺序的三种表达

| 表达 | 实现 | 读出的层级 | 代价 |
| --- | --- | --- | --- |
| 面板压角色 | 单一 z-index，面板不透明 | 面板是前景操作层，角色是背景 | 低 |
| 角色压面板（局部） | 模型 B 前片 z=24 | 角色「探出」界面，最强 | 高（见 20-layering.md 第 5 节） |
| 面板半压角色 | 面板边缘恰好切过角色躯干，面板不透明 | 中等：面板是悬浮层 | 低，但需精确对位 |

**第三种最容易被误做成「半透明面板压在角色身上」**——那会同时损失可读性和纵深感。要么不透明切开，要么全透明只留文字（此时文字必须垫 scrim，见 50-a11y-responsive.md）。

## 3. 禁区与面板布局

禁区（头部矩形）定义在 10-composition.md 第 7 节。面板可用区域是**禁区之外的所有地方**，按优先级：

1. 视线反侧的侧栏（宽度 32–42vw，与角色不重叠）。
2. 底部横条（高度不超过 100% - char-h - headroom × char-h）。
3. 角色前方的浮层卡片（仅 A 模型：面板不透明压住角色躯干，且不得触及禁区）。

| 面板位置 | 允许 | 条件 |
| --- | --- | --- |
| 侧栏 | 是 | 与角色轮廓间距不小于 --af-panel-gap（24px） |
| 底部横条 | 是 | 上沿不超过视口 50%，即不越中枢线 |
| 角色躯干浮层 | 仅 A 模型 | 不覆盖禁区，且面板不透明 |
| 角色面部 | 否 | 情绪性遮挡例外见第 4 节 |
| 跨角色与背景的整宽条 | 是 | 必须有一处被角色前片压住（B 模型），否则变成横幅 |

## 4. 情绪性遮挡的例外

对话框、气泡、状态标签允许进入禁区，但三条同时满足：

- 覆盖禁区面积不超过 8%（约等于「压住下巴，不碰眼睛」）。
- 只压禁区下 1/3（下巴线以下）。
- 有 1px 描边或不少于 8px 的内边距，让人看出这是「放在前面」的东西而不是角色的一部分。

视觉小说式对话框是唯一允许大面积的例外：它压住角色下半身，但**永远不碰禁区**。

## 5. 角色从面板后探出

这是 B 模型的核心手势，做法固定：

```css
.af-panel { z-index: 20; }
.af-char__front { z-index: 24; }   /* 只有前片越到面板之上 */
.af-char__front { clip-path: inset(var(--af-cut) 0 0 0); }
```

选 --af-cut 的三个判据：

1. **切在肢体最窄处**：腰、颈、手腕。切在手指或发束中间 → 断指。
2. **前片必须有可辨识的轮廓**：一只手、一段衣摆、一缕头发。只有 3% 高度的前片读不出「探出」。
3. **前片与面板重叠不少于 24px**：小于这个数，重叠像渲染错误；大于 96px，面板被吃掉太多。

**验收方法**：把前片临时染成 #FF0000，截图看它是否只出现在面板上方、且轮廓完整可辨。

## 6. 面板内部的空间纪律

| 项 | 数值 | 原因 |
| --- | --- | --- |
| 内边距 | 24 / 20（桌面 / 移动） | 小于 16 文字贴边，大于 32 面板显空 |
| 正文行高 | 1.65 | 在立绘背景上，1.5 以下行间会与角色细节混淆 |
| 正文最大行宽 | 34 汉字 / 62 字符 | 超过 40 汉字，眼睛回扫距离过长 |
| 控件最小高度 | 44px | 触摸目标下限 |
| 面板圆角 | 14px 或 0（切角） | 4–8px 的圆角在立绘旁像组件库默认值 |

## 7. 面板与角色的间距

间距不是平均值得，是**沿角色轮廓的最短距离**。角色轮廓在肩部外扩，在腰部内收，所以：

- 侧栏与角色：取角色**最外凸点**（通常是抬起的肘或发尾）与面板的间距，基准 24px。
- 底部横条与角色：取角色裁切线与面板上沿，基准 0（对齐）或 32px（明确悬空），不用中间值。
- 浮层卡片与角色：允许 0（压在躯干上），但不允许「差 6px」——那是没对齐。

## 8. 反例

- 面板四边都描 1px 白边，再加 backdrop-filter 模糊：既是贴纸又是玻璃，两边职责都越界。
- 侧栏宽度 50vw 且角色 anchor-x 取 50%：角色被切成两半，观感像 bug。
- 底部横条高 40% 而 char-h 取 70%：面板上沿越过中枢线，直接压脸。
- B 模型前片用 z-index: 999：之后面板内所有子元素都被压在角色下面。
- 对话框压住眼睛，理由是「视觉小说都这样」：眼睛是唯一识别信息，压住就认不出角色。
- 面板底部与角色裁切线差 12px：看起来像没对齐，而不是刻意悬空。
