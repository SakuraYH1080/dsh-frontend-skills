# 50 · 变体：四场景 × 明暗两套

## 1. 变体的目的

同一套玻璃规则，放到不同产品上必须长得不一样，否则每个用它的产品都是同一张图。
本 skill 控制的是**材质维度**，不控制版式与品牌色。

## 2. 六个可变维度

| 维度 | 取值 | 影响 |
| --- | --- | --- |
| `preset` | thin / standard / deep / frost | 基础工况 |
| `theme` | light / dark | tint 与边框 |
| `tintHue` | neutral / cool / warm / brand | 玻璃的色倾向 |
| `edge` | hairline / soft / thick | 边框与高光强度 |
| `density` | airy / normal / dense | 内边距与圆角 |
| `motion` | full / reduced / none | 是否入场 |

## 3. 四种场景变体

### 3.1 媒体播放器（media）

- `standard` + `tintHue: brand`（取封面主色，α +0.10）
- 播放条单独用 `thin`，因为它在 8px 内要放三个控件
- 封面图会被 blur，所以封面本身要留一块不透明的缩略图作为"锚"

### 3.2 系统面板 / 桌面式（desktop）

- `standard` + `edge: hairline` + `density: airy`
- 圆角 12–16px，比移动端小（桌面更容易被鼠标精确指向）
- 深色版本几乎是必需的（壁纸多是深色）

### 3.3 数据仪表盘（dash）

- `frost` 为主（数据要读得清），只在容器外框用 `standard`
- 禁用折射（`--lg-refraction: 0`），数字不能被位移
- 图表线不能直接画在玻璃上，先垫 `--lg-scrim` α ≥ 0.70

### 3.4 全屏媒体背景（overlay）

- `deep`，tint α 0.55 +
- 必须限制同时可见的玻璃层 ≤ 2
- 视频背景上禁用折射（每帧重算滤镜）

## 4. 明暗两套

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| tint | 白 / 冷白 / 暖白 | `#0C1017` / `#080C14` |
| 边框 | 白 α .40 | 白 α .12–.20（**不是黑**） |
| 内高光 | 白 α .70 | 白 α .30 |
| 外阴影 | 黑 α .12 / .22 | 黑 α .30 / .45（更深） |
| 内容色 | `#11141A` | `#F2F4F8` |
| 焦点环 | `#2563EB` | `#60A5FA` |

**深色不是反色**。深色的玻璃更"贵"，因为它要从暗背景里浮起来，必须靠更强的外阴影而不是更强的边框。

## 5. 变体卡（交付必写）

```text
材质卡
preset: standard ｜ theme: dark ｜ tintHue: cool
edge: hairline ｜ density: airy ｜ motion: reduced
降级：L1 无折射 → L2 blur 6px → L3 实心（α .98）
```

三行以内，写在交付说明最前面。评审时先看这张卡，再看截图。

## 6. 不要照抄示例

`templates/panels.html` 里的产品名、数字、封面都是虚构的。真正的交付必须把这些替换成产品自己的内容，并且能说出"和最接近的示例有哪三处不同"。

## 7. 新组件怎么推

1. 先判断它属于哪一个层级（覆盖层 / 工具层 / 主容器）。第三类不用玻璃。
2. 从四预设里选一个，不从零调参。
3. 检查它旁边是否已有玻璃：有就从层叠衰减表取下一档。
4. 用实验室量一次对比度，不靠眼睛。
5. 写进材质卡。
