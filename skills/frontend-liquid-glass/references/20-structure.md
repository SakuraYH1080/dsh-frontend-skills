# 20 · 结构与状态：玻璃组件的层次语法

## 1. 一个玻璃组件的解剖

```text
┌─ 外阴影层 (box-shadow: far)          给"浮起来"的距离
│ ┌─ 边框 (1px, 白 α .4)                给材料的边界
│ │ ┌─ 底色 tint (rgb / α)             给承载的底
│ │ │ ┌─ 背景滤镜 (blur+sat+bright)    给"透"的证据
│ │ │ │ ┌─ 内高光 (inset 0 1px 0)      给侧壁受光
│ │ │ │ │ ┌─ 内容承载层 (scrim)         给可读性
│ │ │ │ │ │ ┌─ 内容
└─┴─┴─┴─┴─┴─┘
```

顺序即 z 序。任何一层缺失都能被看出来，任何一层多余都会变脏。

## 2. 六种状态

| 状态 | 变化 | 不变的 |
| --- | --- | --- |
| 静置 | 基准参数 | — |
| 悬停 | `--lg-tint-alpha +0.06`，边框 α +0.08 | blur、折射（**不要改 blur**） |
| 按下 | `--lg-brightness -4%`，位移 `translateY(1px)` | 尺寸、阴影方向 |
| 聚焦 | 2px 焦点环，`outline-offset: 2px` | 玻璃参数全部不变 |
| 禁用 | `--lg-tint-alpha 0.98`，内容 α 0.38，去掉阴影 | 边框仍在（否则看不出边界） |
| 加载 | 内容区加一条 1px 强度扫描；玻璃本体不动 | 玻璃参数全部不变 |

**规则：状态变化只改"材料的重量"，不改"材料的种类"。** 改 blur 是一种类型变化，会让人以为换了一个组件。

## 3. 五种真实组合

### 3.1 顶部导航（`standard`，贴边）

- 只有左右下三条边有边框，上边没有（贴着视口边）。
- 滚动时提高 tint α（0.42 → 0.52），**不改 blur**。
- 高度 56–72px；内容与玻璃边界至少留 16px。

### 3.2 侧栏（`standard`，贴边内侧）

- 玻璃宽度 ≥ 280px，否则模糊半径相对宽度过大，像雾。
- 与主内容之间用 1px 边线，不用投影（投影会暗示它可以浮走）。

### 3.3 播放器 / 控制条（`thin` 或 `standard`）

- 内有封面图时，用封面的主色做 tint，α 提高 0.10（否则会被背景吃掉）。
- 进度条不能放在玻璃上直接画细线：细线在模糊背景上会抖动，需要先垫 scrim。

### 3.4 模态弹窗（`deep`）

- 背后必须有一层遮罩（`rgba(0,0,0,.32)`），否则弹窗与背景竞争。
- 弹窗本身 tint α ≥ 0.55，正文对比度按最亮背景计算。
- 出现与消失用 240/160ms，遮罩用同一条曲线但时长 ×1.4。

### 3.5 底部抽屉（`deep`，圆角在上）

- `border-radius: 22px 22px 0 0`。
- 顶部有一条 36×4 的把手，把手本身就是拖动热区（≥44px 高的隐形热区）。
- 抽屉高度变化时**不要**让玻璃跟着逐帧重算：用 `will-change: transform` 只在动画期间存在，动画结束立即移除。

## 4. 层叠的可解释性

多层玻璃叠在一起时，用户必须能回答："哪一层在上一层的上面，为什么？"

三条规则：

1. **每层必须有不同来源的投影强度**（越近 far 越大）。
2. **每层必须有可见的 1px 边界**，且边界的亮度按层递增。
3. **不允许两层玻璃完全重叠且参数相同** —— 那看起来是一层，但会双倍开销。

## 5. 与内容的接触

- 玻璃内边距 ≥ 16px（移动端）/ 20px（桌面），否则内容像贴在边上。
- 玻璃上的分隔线用 `rgba(0,0,0,.08)`（浅色）/ `rgba(255,255,255,.10)`（深色），**不要**用实心灰，会在模糊背景上跳。
- 玻璃上的图标用单色，不要彩色 emoji（彩色在高饱和背景上会打架）。

## 6. 反例

- 玻璃卡片里再放玻璃卡片，参数一致 → 看起来一层，实际两层，掉帧。
- 导航栏 blur 24px，下拉菜单 blur 24px 且完全叠在导航栏上 → 边缘消失。
- 悬停时 blur 从 24 变 32 → 每帧重建，移动端直接掉到 20fps。
- 玻璃上放细线图表 → 线在模糊背景上抖动，读数困难。
