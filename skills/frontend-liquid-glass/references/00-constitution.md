# 00 · 玻璃的宪法：它为什么像玻璃，以及什么时候不该出现

## 1. 一句话立场

玻璃不是一种装饰，是一种**层级证据**。它告诉用户："这层东西在你面前，不在页面里。"
一旦这个信息不成立，玻璃就只剩成本。

## 2. 四个成因，缺一即塌

### 2.1 模糊（scattering）

真实玻璃的表面有微观起伏，穿过它的光被散射，细节消失但明暗分布保留。

- 代码：`backdrop-filter: blur(Npx)`
- 有效范围：8–48px。低于 6px 时背景纹理仍能干扰文字；高于 48px 时背景变成纯色块，玻璃失去"透"的证据。
- 关键性质：blur 是**低通滤波**。它保留低频（大色块、明暗），杀掉高频（文字、细线、噪点）。所以玻璃后面的"内容"越是大色块，玻璃越好看；后面是密集小字时，玻璃反而制造脏。

### 2.2 折射（refraction）

厚度导致光路偏移，边缘处偏移最大，形成"边缘放大 / 边缘错位"。

- 代码：`feDisplacementMap`（web），或边缘 `scale(1.02)` 的伪变形
- 关键性质：折射是**边缘现象**。中间平的地方不该有位移。很多实现错在整块都位移，看起来像果冻。
- 强度：位移 3–12px。超过 18px 变成水波纹。

### 2.3 边缘高光（specular）

侧壁受光。上沿一条 1px 亮线，下沿一条更暗的线，左右几乎不出。

- 代码：`inset 0 1px 0 rgba(255,255,255,.7)`、`inset 0 -1px 0 rgba(255,255,255,.2)`
- 关键性质：高光的方向必须和光源一致且全站统一。一半组件高光在上、一半在下，材料立刻失真。

### 2.4 环境色渗透（transmission）

玻璃不是中性的，它把背景的颜色带进来，并且略微提高饱和度。

- 代码：`saturate(130–180%) brightness(104–116%)`
- 关键性质：这一步决定了玻璃"有没有颜色"。缺了它，玻璃永远是灰色半透明。

## 3. 层级伦理

玻璃的语义是"更近"。因此：

| 应该 | 不应该 |
| --- | --- |
| 覆盖在内容之上的工具层 | 承载页面主体内容的容器 |
| 临时出现的模态 / 抽屉 | 常驻的第一屏背景 |
| 与主内容并置的辅助面板 | 主内容本身 |
| 一层到两层 | 四层以上 |

推论：**一个界面里玻璃的面积占比不应超过 25%**。超过之后，"浮起来"不再是信息。

## 4. 什么时候不该用玻璃

1. 背景是纯色：没有任何东西可透，玻璃只是浪费 GPU。
2. 背景是高对比细节（密集文字、表格、照片纹理）：blur 之后仍然脏。
3. 内容是长文阅读：玻璃的对比度随背景漂移，长文无法稳定阅读。
4. 需要精确取色（设计工具、调色、医学影像）：玻璃会改色。
5. 性能受限设备且无降级路径。
6. 用户明确要求扁平 / 工业 / 极简硬边风格 —— 那是别的 skill 的领域。

## 5. 一票退回清单

- 用 `filter: blur()` 模糊元素自身（内容一起糊）。
- 只写 `-webkit-backdrop-filter` 或只写标准属性。
- 玻璃上放 12px 以下的浅灰字。
- 三层以上玻璃叠加。
- 没有降级路径。
- 用玻璃遮住关键信息，靠 hover 才显示。
- 把玻璃当"高级感"贴纸，页面里所有卡片都加。
