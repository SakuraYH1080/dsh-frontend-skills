开始

安装与初始化

本模板不依赖任何构建工具。把仓库放在本地，用一条命令起静态服务即可。

1. 起本地服务

直接双击 HTML 能看排版，但滚动叙事的 IntersectionObserver 在 file:// 下仍可用；只有 ES module 会被拦。

python3 -m http.server 8000，然后打开 localhost:8000/templates/docs-page.html。

不要把 script 写成 type="module"：本地文件协议下 module 会被 CORS 拦掉，页面会留在未初始化状态。

2. 布局与网格

所有间距是 8 的倍数。三栏宽度固定为 240 / 600 / 200，中栏不允许拉伸到 720 以上。

  • 600px ÷ 17px ≈ 35.3 个汉字，或 70.6 个英文字符 —— 这是回读时眼睛不丢行的上限。
  • 栏间距 32px。缩到 24px 时两栏会被读成一块。
  • 右侧 200px 只放锚点与「本页更新于」，不放正文。

3. 字号与字阶

正文 clamp(16px, 0.125vw + 15.4px, 17px)，行高 1.65。低于 16px 的正文在 1440 屏上会被读成脚注。

标题字重 600，字距 -0.03em。中文不要用 700：笔画会在小字号上糊成一团。

4. 留白节奏

同主题两段之间 64px，主题切换 128px，展示级分隔 160px。三个数字之外没有第四种间距。

间距一旦全用同一个值，层级就只剩字号在承担 —— 那时再多加一条分割线也没用。

5. 滚动叙事

元素进到视口下沿 12% 才算进入，可见面积 15% 才触发。默认态是已显示，脚本只在能跑的时候加 .js-scroll。

不要用滚轮劫持做整段钉住：锚点跳转会失效，浏览器的前进后退也会停在错误位置。

6. 交付检查

  • 每个 section 只有一个主张，能在 8 个字内说清。
  • 正文宽度 ≤ 600px，无一处例外。
  • 所有间距是 8 的倍数。
  • 关掉 JS，页面仍完整可读。
  • 「减少动态效果」下没有任何位移。
