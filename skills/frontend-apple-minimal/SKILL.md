# 苹果式极简 · 信息层级与滚动叙事（frontend-apple-minimal）

这个 skill 只做一件事：**决定一页上什么东西在什么位置、占多少空间、以什么速度出现**。

它不决定材质。玻璃、粒子、HUD、角色立绘都不归它管；它给的是骨架 —— 一页分几段、每段主张是什么、空白在哪里、滚到第几屏时该发生什么。骨架对了，套任何皮肤都成立；骨架错了，加什么材质都是给信息墙刷漆。判断标准只有一条：**删掉这个元素之后，读者是否损失了信息**，不损失就删。

## 一、什么时候用 / 不用

**用**

- 要做一个以文字、数据、产品图为主的长页（发布页、落地页、品牌主页、文档首页）。
- 页面已经有内容，但读者滚到第三屏就不知道自己在看什么 —— 缺的是分段与主张，不是配色。
- 字号从 14 到 60 随手挑了七八个值，间距有 20/30/40/50 四套，整体看起来"哪里都对、合起来不对"。
- 首屏是"导航 + 大标题 + 两行副标题 + 两个按钮"的标准模板，要换成有主张的结构。
- 要给长页加滚动揭示、sticky 段落、视差，但不确定该用哪种、参数取多少。
- 移动端字太大换行难看、或栏宽在 27 寸屏上拉到 120 字符读不下去。

**不用**

- 要玻璃、毛玻璃、半透明浮层、折射边缘 → 交给 `frontend-liquid-glass`。这里只给不透明的分层底色与 1px 描边。
- 要星空、粒子、流体背景、WebGL 场景 → 交给 `frontend-particles`。极简页的背景是纯色或单向渐变，不加动态背景。
- 要二次元角色界面、立绘、对话框、拟人化导航 → 交给 `frontend-anime-fusion`。
- 要 HUD、切角、扫描线、仪表盘、高密度操作台 → 交给 `frontend-industrial-sci-fi`。
- 只要一个单页海报、一个弹窗、一个卡片组件 —— 没有滚动，没有分段，用不上叙事结构。
- 需求是"炫"而不是"读"：一屏要放六个卖点、要动效铺满 —— 那是别的问题，硬套极简只会显得空。

上面四条是默认边界，不是永久隔离。用户明确要求组合时（例如"苹果极简 + 局部玻璃"），组合才发生，且必须指定一个主导语言：结构、层级、留白与滚动节奏归本 skill，frontend-liquid-glass 只能做局部增强 —— 浮起来的导航条、一张信息卡、一个底部抽屉；材质参数只改那一块，不改版面骨架，也不改字阶与间距阶梯。任何让玻璃占据整屏背景、或让粒子铺满留白的组合，都是把主导权交了出去，退回不用。

## 二、核心原则与硬边界

### 原则 1：一屏一个主张，主张必须是句子

每屏（约 1 个视口高）只允许一个主张存在。主张写成**一句可反驳的话**，不是名词短语：写"每块玻璃只模糊一次"，不写"高性能材质"。

为什么：名词短语没有信息量，读者无法判断真假，只能扫过去；句子会引发"是吗？"的反应，读者才会往下读证据。这就是极简页能撑住大片留白的唯一原因 —— 留白里有一个待回答的问题。

**失效症状**：首屏同时出现标题、三条副标题、四个图标、两个按钮，读者的眼睛没有落点，视线在四个角落之间跳，2 秒后离开。

### 原则 2：三层结构，且层数不可增加

| 层 | 内容 | 字号 | 每段数量 |
| --- | --- | --- | --- |
| 主张 | 一句可反驳的话 | `--fs-h2` 或以上 | 1 |
| 证据 | 图、数据、代码、对比 | 无文字或 `--fs-caption` | 1–3 |
| 细节 | 参数、脚注、条件说明 | `--fs-small` 15px / `--fs-caption` 13px | 0–5 |

加第四层（比如"证据的解释"）会让读者在同一屏里做两次认知切换。真要解释，把它挪到下一段的细节层。

### 原则 3：间距只有一档基准，其余全是它的倍数

所有间距从 **8px** 派生：内容内 8/16/24/32，段间 64/96/128/160。不出现 20px、30px、50px。

为什么是 8 而不是 4 或 10：8 能被 2 与 4 整除，在任何 DPR（1/1.5/2/3）下都落在物理像素整点上；4 太碎，会让人忍不住在每处都微调，最终出现 20/28 这种非整倍数；10 与 12 的公约数只有 2，屏上一半的间距会落在半像素。**间距一旦有第二套刻度，页面就会开始"手调感"。**

### 原则 4：正文栏宽由字号决定，不由容器决定

容器 1120px 是**最大**宽，正文永远是 **600px**（`--measure`）。17px 下 600px ≈ 中文 35 字/行、英文 71 字符/行。

为什么不是百分比：容器变宽时百分比栏宽也跟着变，在 1920 屏上会拉成 90 字符/行，回读时眼睛找不到下一行开头（超过 75 字符，扫视落点误差超过一行）。**栏宽是一个绝对量，跟着字号走，不跟着屏幕走。**

### 原则 5：灰阶是九个固定的角色，不是一个连续调色盘

`--n-0` 到 `--n-8` 各自绑定用途：0 页面底、1 分区底、2 分隔块、3 禁用边、4 次要文字（2.80:1，**只用于装饰性文字**）、5 正文辅助（4.70:1）、6 正文（8.52:1）、7 标题（12.88:1）、8 反色底。深色模式不是把它们倒过来，而是重新映射到一组实测过的组合上。

**硬边界**：本 skill 只决定信息层级、留白节奏与滚动叙事。玻璃材质、粒子背景、HUD 装饰、角色立绘不在职责内，即使它们能让画面更丰富。

### 一票退回

- 首屏出现两个以上同等重量的主张（两个大标题、两段等长的解释）。
- 正文栏宽超过 660px 或小于 520px。
- 出现三套以上间距值（例如同时有 20、24、30、48）。
- 标题字距为正（大字加字距会让标题散架）。
- 强调色在两屏内出现超过 4 次，或出现第二种彩色。
- 正文对比度 < 4.5:1，或 15px 以下文字用 `--n-4` / `--n-5`。
- 滚动区里用了 `scroll-behavior: smooth` 做逐段吸附（scroll-hijack）。
- 揭示动画的初始态是 `opacity: 0` 且 JS 未加载时元素仍然不可见。
- 容器上写了 `overflow: hidden`，导致内部 `position: sticky` 静默失效。
- 深色模式用 `filter: invert()` 或直接反色实现。

## 三、可调参数与设计变体

权威数值在 `assets/tokens.json`，落到 CSS 是 `assets/apple-minimal.css` 的 `:root`。下表的每个值都能在这两个文件里对上；三处不一致时以 tokens.json 为准。

**基础刻度**

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--u` | 8px | 一切间距的基准单位 |
| `--gap-1/2/3/4` | 8 / 16 / 24 / 32px | 内容内间距（标题到正文用 2，段落之间用 3） |
| `--section-xs/s/m/l` | 64 / 96 / 128 / 160px | 段与段之间的空白 |
| `--container` | 1120px | 常规最大宽 |
| `--container-wide` | 1440px | 全幅视觉块 |
| `--measure` | 600px | 正文栏宽（中文 35 字 / 英文 71 字符） |
| `--measure-narrow` | 480px | 图注、引文、侧栏文字 |
| `--gutter` | `min(6vw, 96px)` | 页面左右留白 |

**字阶（`--fs-*`，两套比例任选其一，全域只能一套）**

| 角色 | 值 | 行高 | 字距 | 字重 |
| --- | --- | --- | --- | --- |
| `--fs-h1` | `clamp(40px, 4vw + 20.8px, 72px)` | 1.08 | −0.04em | 600 |
| `--fs-h2` | `clamp(30px, 2.25vw + 19.2px, 48px)` | 1.12 | −0.03em | 600 |
| `--fs-h3` | `clamp(23px, 0.875vw + 18.8px, 30px)` | 1.2 | −0.02em | 600 |
| `--fs-lead` | `clamp(18px, 0.375vw + 16.2px, 21px)` | 1.45 | 0 | 400 |
| `--fs-body` | `clamp(16px, 0.125vw + 15.4px, 17px)` | 1.65 | 0 | 400 |
| `--fs-small` | 15px | 1.5 | 0 | 400 |
| `--fs-caption` | 13px | 1.4 | +0.01em | 500 |

`1.25` 比例：17 / 21 / 27 / 33 / 41 / 52；`1.333` 比例：17 / 23 / 30 / 40 / 54 / 72。**两套差别的实际后果**：1.25 的层级更密，适合信息多的文档；1.333 对比更强，适合一句话主张的发布页。混用会让 h2 在某一段突然比相邻段的 h3 只大 2px。

**动效（`--t-*` 与 `--ease-*`）**

| 变量 | 值 | 用在哪 |
| --- | --- | --- |
| `--t-1` | 120ms | 悬停、按下、焦点环 |
| `--t-2` | 240ms | 揭示动画、卡片进视口 |
| `--t-3` | 400ms | 段落切换、视差收敛 |
| `--t-4` | 650ms | 首屏一次性入场 |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场默认 |
| `--ease-in` | `cubic-bezier(0.7, 0, 0.84, 0)` | 离场（时长 ×0.6） |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 状态往返 |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 位置移动 |

**四套预设**

| 预设 | 比例 | 段间距 | 栏宽 | 特征 |
| --- | --- | --- | --- | --- |
| `product-launch` | 1.333 | 96 / 128 / 160 | 600px | 大留白、纯排版 hero、参数表收尾 |
| `docs` | 1.25 | 64 / 96 | 600 / 480px | 三栏 240/600/200、双侧 sticky、目录常驻 |
| `brand` | 1.333 | 128 / 160 | 520px | 极短文案、单图占满、段落数 ≤ 5 |
| `app-landing` | 1.25 | 64 / 96 / 128 | 560px | 竖屏截图为主、每段一功能、CTA 在第 3 与末段 |

预设只改比例、间距、栏宽三个旋钮；换预设不换曲线、不换断点、不换灰阶。**一个站只用一套预设。**

## 五、执行流程

1. **写主张清单**：一页写 4–7 句可反驳的话，每句一行，不加修饰。少于 4 句说明内容不够撑一页，多于 7 句说明有两句在讲同一件事。
2. **排序**：第一句必须是"读者为什么要在意"，最后一句必须是"现在做什么"。中间按"是什么 → 怎么做到 → 代价多少"排。
3. **选变体**：按 `60-variants.md` 的变体卡选一套预设，写进交付说明的"版式卡"（三行：预设 / 比例 / 栏宽）。
4. **配间距**：给每两段之间指定 `--section-s/m/l`，相邻两段不得同档；页首与 CTA 用最大档。
5. **定字阶**：全站只用一套比例，把 h1/h2/h3/lead/body 五个 clamp 值写进 `:root`，正文栏宽锁 600px。
6. **过删减四问**（见 `00-constitution.md` 第三节）：删掉后是否损失信息 / 是否是证据 / 是否能移到下一段 / 是否只是填充。四问都通过才保留。
7. **排滚动**：标出哪 2–3 段需要 sticky 或视差，其余用一次性揭示；写清触发阈值与降级路径。
8. **配动效**：从 120/240/400/650 里选，入场用 `--ease-out`，错开 60–90ms 且不超过 4 个元素。
9. **过三档宽度**：640 / 900 / 1200 各看一次，确认没有段落在此处从两栏塌成一栏后留白翻倍。
10. **过检查清单**：逐条打勾，任何一条不过就回到对应步骤，不要用"整体看起来还行"收尾。

## 六、交付检查清单

- [ ] 一页有 4–7 个 section，每个 section 只有一句主张，且主张是完整句子。
- [ ] 全站只用一套字阶比例（1.25 或 1.333），标题字距在 −0.02em ~ −0.04em 之间且为负值。
- [ ] 正文 `max-width` 为 600px（±20px），在 1440px 与 1920px 视口下实测行宽不变。
- [ ] 所有间距值 ∈ {8,16,24,32,64,96,128,160}，没有其他数值。
- [ ] 灰阶只用 tokens 里的九个值，没有临时调的 `#666` / `#888` 一类。
- [ ] 彩色只有一个（`#0A6CFF` 或 `#0055D4` 文字版），出现次数 ≤ 4 次/两屏。
- [ ] 正文对比度 ≥ 4.5:1，标题 ≥ 3:1，实测值写在交付说明里。
- [ ] 动效时长 ∈ {120,240,400,650}ms，只动 `transform` 与 `opacity`。
- [ ] `prefers-reduced-motion: reduce` 下无位移、无缩放，内容全部可见。
- [ ] 禁用 JS 后所有 `[data-reveal]` 元素仍然可见（默认态是已显示）。
- [ ] 滚动容器与所有祖先没有 `overflow: hidden`（否则 sticky 失效）；需要裁剪时用 `overflow: clip`。
- [ ] 触控目标 ≥ 44×44px，主导航与 CTA ≥ 48px 高。
- [ ] 640 / 900 / 1200 三档宽度下无横向滚动、无文字重叠。
- [ ] 深色模式下正文对比度 ≥ 4.5:1（实测 `#C6C6CB` on `#0A0A0C` = 11.62:1）。
- [ ] 页面里没有任何 http(s) 外链资源，字体只用系统字体栈。
