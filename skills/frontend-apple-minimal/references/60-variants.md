# 60 · 四种页面类型变体

每个变体是一张「卡」：结构、参数覆盖、判据、失败样例。选一张，把它的覆盖项合并进 tokens.json 的预设。

---

## 变体 1 · 产品发布页（product-launch）

### 结构

```
hero（纯排版或分栏）
  ↓ 160px
特写 A（满幅图 + 一句标题）
  ↓ 96px
特写 B（左文右图）
  ↓ 96px
特写 C（右文左图，可选）
  ↓ 128px
参数段（两列表格）
  ↓ 128px
CTA（大标题 + 一个按钮）
  ↓ 64px
footer
```

### 参数覆盖

| 参数 | 值 | 与默认的差异 |
|---|---|---|
| 字阶比例 | 1.333 | 大档差，一屏三层 |
| section 间距 | 96 / 128 / 160 | 用满三级 |
| 正文栏宽 | 600px | 默认 |
| 强调色 | 只用在主 CTA | 出现次数 1 |
| hero 高度 | `min(88vh, 820px)` | 默认 |

### 判据

- 首屏必须能读到：产品名、一句话、一个按钮。
- 特写 2–4 个，每个回答一个不同问题。
- 参数段 ≤ 12 项，超出折叠。
- CTA 3–4 处，文案一致。

### 失败样例

八段特写、每段一句形容词、参数段 40 行、CTA 出现在每个 section。结果：页面变长 3 倍，转化率不升。
原因：特写超过 4 个后，读者在第 5 个之前已经形成判断，后面的内容是给自己看的。

## 变体 2 · 文档站（docs）

### 结构

```
┌─────────┬──────────────┬────────┐
│ 左侧目录 │   正文 600px  │ 右侧锚点│
│ 240px   │              │ 200px  │
│ sticky  │              │ sticky  │
└─────────┴──────────────┴────────┘
```

### 参数覆盖

| 参数 | 值 | 说明 |
|---|---|---|
| 字阶比例 | 1.25 | 档位多（h1–h4 + 代码 + 表格），需要温和 |
| 正文栏宽 | 600px | 中文 35 字 |
| section 间距 | 64 / 96 | 不用 160，文档要密 |
| 侧栏宽度 | 240 / 200 | 目录项 14px，行高 32px |
| 强调色 | 只用于当前页高亮与链接 | 出现位置 2 类 |

### 判据

- 三栏在 < 1200px 时收为两栏（右锚点收起），< 900px 时收为一栏（左目录变抽屉）。
- 目录项高度 ≥ 32px（点击）+ 上下 padding 到 44px 命中区。
- 代码块横向滚动，不换行；`overflow-x: auto` 且不在祖先加 `hidden`。
- 当前章节高亮用 `IntersectionObserver` 的 `rootMargin: "-45% 0px -45% 0px"`，让「视口中线所在的标题」成为当前项。

### 失败样例

左侧目录可滚动但整页 `overflow: hidden` 包住，导致 `position: sticky` 全部失效。修法：容器改 `overflow: clip`。

## 变体 3 · 品牌站（brand）

### 结构

```
hero（纯排版，h1 独占一屏）
  ↓ 160px
一句主张 + 一段 200 字自述
  ↓ 160px
作品/项目列表（4–9 项，2–3 列）
  ↓ 160px
联系方式
```

### 参数覆盖

| 参数 | 值 | 说明 |
|---|---|---|
| 字阶比例 | 1.333 | h1 可到 72px |
| 正文栏宽 | 520px | 比默认窄，编辑感更强 |
| section 间距 | 128 / 160 | 大量留白是主体 |
| 强调色 | 0 处或 1 处 | 多数品牌站可以完全不用色 |
| 图片 | 统一 4:5 或 1:1 | 不混比例 |

### 判据

- h1 之后必须紧跟一句不超过 30 字的说明，否则访客不知道你是谁。
- 作品列表的图比例必须统一；混用 16:9 与 1:1 会让列表失去节奏。
- 不用 hover 才显示的信息（触屏没有 hover）。

### 失败样例

全站只有一张全屏图和一句诗。访客停留 4 秒离开——因为没有任何「你是谁、做什么、怎么联系」的信息。极简不等于信息缺失。

## 变体 4 · 应用落地页（app-landing）

### 结构

```
hero（分栏：左文右设备框）
  ↓ 96px
三功能（3 列，图标 + 标题 + 一句）
  ↓ 96px
一张大截图（满幅或容器内）
  ↓ 128px
评价（2–3 条引言）
  ↓ 96px
下载 CTA（二维码或两个商店按钮）
```

### 参数覆盖

| 参数 | 值 | 说明 |
|---|---|---|
| 字阶比例 | 1.25 | 功能标题只需 h3 |
| 正文栏宽 | 560px | 稍窄，配合设备框 |
| section 间距 | 64 / 96 / 128 | 中等 |
| 强调色 | CTA + 1 处数据高亮 | ≤ 2 处 |
| 设备框 | 圆角 24px，边框 1px #EDEDEF | 用 CSS 绘制，不用素材图 |

### 判据

- 三个功能必须回答三个不同的问题，不能是「快 / 更快 / 最快」。
- 设备框内的截图必须有真实内容（哪怕是占位文字），空框看起来像没做完。
- 下载 CTA 在首屏与页尾各一次，中间不加。

### 失败样例

首屏放手机模型 + 三行字，但没有说明「这是干什么的」。移动端用户看不到模型里的细节，等于首屏空白。

## 变体选择表

| 你的页面要… | 选 | 关键差异 |
|---|---|---|
| 卖一个具体物件 | 1 发布页 | 特写段 + 参数表 |
| 让人查资料 | 2 文档站 | 三栏 + sticky 目录 |
| 建立个人/工作室形象 | 3 品牌站 | 大留白 + 统一图比例 |
| 让人下载 App | 4 落地页 | 设备框 + 商店按钮 |

### 混用的边界

允许：发布页的参数段样式借给落地页；文档站的目录样式借给品牌站的案例列表。
不允许：文档站的三栏骨架套在发布页上（读者会以为是说明书）；品牌站的 160px 留白套在文档站上（信息密度崩）。

---

## 规则

- **规则**：先选变体，再从变体卡取参数覆盖，不要现场调和。
- **规则**：一个页面只用一个变体的骨架，样式可借，结构不可借。
- **规则**：每个变体的「失败样例」在交付前对照一次。
