# 20 · 大幅视觉叙事：hero 结构与 section 编排

---

## 1. hero 的三种结构

### 结构 A · 全幅媒体

```
┌──────────────────────────────┐
│                              │
│         [满幅 16:9 媒体]      │  ← 高度 clamp(420px, 56vw, 820px)
│                              │
├──────────────────────────────┤
│  h1（居中或左下）              │  ← 与媒体重叠 0–48px
│  lead + CTA                   │
└──────────────────────────────┘
```

- 适用：产品形态本身就是视觉的（硬件、设备、影像）。媒体必须**自有**（CSS/SVG 绘制或用户提供的素材）。
- 关键参数：媒体 `aspect-ratio: 16/9`；h1 与媒体重叠 0–48px，超过 48px 会遮住产品；媒体底部加一层 `linear-gradient(transparent, rgba(0,0,0,.35))` 保证白字可读。
- 不适用：媒体只是装饰（抽象渐变、几何图形）——那会让首屏变成壁纸，主张被稀释。

### 结构 B · 分栏文字 + 产品

```
┌────────────┬─────────────────┐
│ h1         │                 │
│ lead       │   [产品图 1:1]   │
│ CTA        │                 │
└────────────┴─────────────────┘
   5fr            7fr
```

- 适用：需要在首屏同时给「一句话」和「产品长什么样」。
- 关键参数：`grid-template-columns: 5fr 7fr`；间距 64px；`<900px` 时改为上下堆叠，文字在上。
- 理由：5:7 让文字块约占 42%，正好容纳 600px 栏宽里的 480–520px（窄栏），不浪费。

### 结构 C · 纯排版

```
┌──────────────────────────────┐
│                              │
│   h1（clamp 40→72px，两行内） │
│                              │
│   lead（≤ 34 字）             │
│   [CTA] [次级链接]            │
│                              │
└──────────────────────────────┘
   上下 padding: clamp(96px, 14vh, 200px)
```

- 适用：产品还没图、或主张本身就是一句话。也是最难做假的一种——没有图掩护，字号与字距必须准。
- 关键参数：h1 最多两行，超过两行说明这句话该删；lead ≤ 34 个中文字；CTA 与次级链接间距 24px。
- 反例：纯排版 hero 里放三个按钮。三个同级 CTA 等于没有 CTA。

### 三种结构的选择判据

| 条件 | 选 |
|---|---|
| 产品有强视觉形态，且媒体可自制 | A |
| 需要同时说明「是什么」和「长什么样」 | B |
| 主张本身足够强，或暂无视觉素材 | C |
| 首屏必须完成一次转化 | B 或 C（A 的 CTA 容易被媒体吞掉） |

## 2. 产品页 section 编排

### 四段主线

| 段 | 回答 | 典型高度 | 内容形态 |
|---|---|---|---|
| 1 主张 | 这是什么 | 1 视口 | hero |
| 2 特写 | 凭什么好 | 1–1.5 视口 × 2–4 | 大图 + 短标题 + 一句说明 |
| 3 参数 | 具体是多少 | 0.8–1.2 视口 | 表格 / 规格网格 |
| 4 CTA | 现在做什么 | 0.6–0.8 视口 | 大标题 + 一个按钮 + 价格或条件 |

### 为什么是这个顺序

读者的决策链是「感兴趣 → 相信 → 核对 → 行动」。顺序错了会出现两种典型失败：
- 参数在前（先给表格）：读者在没有理由的情况下被要求读数字，跳出率最高。
- CTA 在前（首屏就催）：没有信任基础，点击率低且退款率高。

### 特写段的数量上限

2–4 个。每个特写回答一个**不同**的问题（更轻 / 更快 / 更耐用 / 更省电）。第 5 个开始，边际说服力接近 0，读者已经形成判断。

**反例**：8 个特写 section，每个都是「大图 + 一句形容词」。读者滑到第 4 个就开始找底部按钮。

### 参数段的排法

- 两列（`grid-template-columns: repeat(2, minmax(0,1fr))`），每项 `dt` 用 #73737B 14px，`dd` 用 #31313A 15px。
- 分组用 `--gap-4`(32px) 分隔，组内 `--gap-2`(16px)。
- 参数超过 12 项时折叠到「查看完整规格」，不要一屏铺 30 行。
- 单调的数字没有说服力：给每项加一个参照（`1.24kg，比上代轻 180g`）。

### CTA 的位置与次数

| 位置 | 是否必要 | 说明 |
|---|---|---|
| hero 内 | 必要 | 首屏必须能行动 |
| 特写段之后 | 可选 | 只在特写超过 2 段时加，否则节奏太急 |
| 参数段之后 | 必要 | 读者刚核对完，是转化峰值 |
| 页尾 | 必要 | 兜底 |

合计 3–4 处，同一文案、同一目标。**超过 4 处**会让人怀疑你在推销而不是介绍。

## 3. 图文节奏

### 交替规则

| 上一段 | 下一段 | 效果 |
|---|---|---|
| 左文右图 | 右文左图 | 视线走 Z 字，节奏稳 |
| 左文右图 | 左文右图 | 重复三次以上形成「表格感」 |
| 全幅图 | 分栏 | 有呼吸，推荐用于段与段之间 |
| 全幅图 | 全幅图 | 两张连着会让页面变成相册 |

### 图的三种处理

1. **满幅（bleed）**：宽度 100vw，高度 `clamp(320px, 42vw, 640px)`，`object-fit: cover`。用于转折。
2. **容器内**：宽度 = `--container`，圆角 0 或 12px（二选一，不要混）。
3. **嵌入文字流**：宽度 = `--measure`，居中，上下各 32px。用于证据型小图。

### 间距与图的关系

图与上下文的间距要比文字段落之间**大一级**：文字 32px → 图 64px。理由：图的视觉重量大，同样的间距下会显得挤。

---

## 4. 长页的呼吸点

任何超过 6 个 section 的页面，需要在第 3–4 段之间插入一个**呼吸点**：

- 一句独立的大字引言（`clamp(24px, 2vw, 34px)`，居中，上下各 128px），或
- 一条全宽分隔带（#F8F8F9 底，高度 160px，内含一行小字），或
- 一次留白（纯 160px 空白）。

没有呼吸点，读者在第 4 段之后会把后面所有内容当成同一块，滚动速度提升、停留时间下降。

---

## 5. 规则

- **规则**：hero 三选一，写理由；不混用两种结构。
- **规则**：section 顺序按「主张 → 特写 → 参数 → CTA」，插入段必须服务其中一段。
- **规则**：特写 2–4 个，CTA 3–4 处，同一文案。
- **规则**：每 3–4 段插一个呼吸点。
